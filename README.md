CTF Write-Ups

This repository contains detailed write-ups of Capture the Flag (CTF) challenges that I have completed as part of my cybersecurity training and continuous learning. Each write-up documents my approach to solving the challenge, including reconnaissance, analysis, tools used, methodology, commands, screenshots, and lessons learned.

The goal of this repository is to demonstrate practical problem-solving skills across multiple cybersecurity domains while maintaining clear, reproducible documentation. Challenges cover areas such as web security, digital forensics, reverse engineering, cryptography, binary exploitation, OSINT, network analysis, and malware analysis.

Objectives
1. Document my learning journey through CTF challenges.
2. Develop structured technical reporting and documentation skills.
3. Showcase practical cybersecurity knowledge and analytical thinking.
4. Build a portfolio of hands-on experience for cybersecurity roles.
5. Share methodologies and techniques that can help others learn.

Write-Up Structure
Each write-up includes:
1. Challenge Information
2. Challenge Description
3. Objective
4. Environment and Tools Used
5. Step-by-Step Methodology
6. Commands and Scripts
7. Screenshots and Evidence
8. Flag
9. Lessons Learned
10. References
